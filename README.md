# List big files in remote git repo

Run in docker:
``` bash
sudo GIT_REPO_URL=https://github.com/user/REPO.git docker compose up
```

Get organization:
``` bash
sudo GIT_REPO_URL=https://github.com/orgs/ORGANIZATION docker compose up
```


Get user:
``` bash
sudo GIT_REPO_URL=https://github.com/users/USERNAME docker compose up
```
